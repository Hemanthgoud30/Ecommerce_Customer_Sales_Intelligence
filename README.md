# E-Commerce Customer & Sales Intelligence

## Project Overview

This project analyzes e-commerce transaction data to identify high-value customers, potentially at-risk customers, revenue patterns, product performance, and business opportunities.

The project was developed as part of the AICTE | IBM SkillsBuild Data Analytics with AI Internship 2026.

## Project Objective

The main objectives of this project are to:

- Analyze overall sales and revenue performance.
- Identify important products and geographic markets.
- Analyze monthly revenue trends.
- Segment customers using RFM analysis.
- Identify potentially at-risk customers.
- Generate business insights and recommendations.
- Build an interactive Streamlit dashboard.

## Dataset

The project uses the **Online Retail** dataset from the UCI Machine Learning Repository.

Dataset Source:

https://archive.ics.uci.edu/dataset/352/online+retail

The dataset contains transactional records from an online retailer, including invoice numbers, products, quantities, prices, customer IDs, dates, and countries.
